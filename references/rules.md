# 编辑规则库：50 条规则、判断标准与候选信号词表

**使用原则：**

- 规则和词表是**候选信号，不是词语黑名单**。命中只说明"值得看一眼"，是否真有问题由语义判断决定。
- 标记前先过五问：这处表达有没有真实信息？是否忠于原意和作者立场？是否服务目标读者和体裁？是否与全文重复？改完后作者能否认可并解释？
- 四种动作的含义：
  - **删**：冗余，删除不损失信息；只用于 SKILL.md"删除许可"范围。
  - **改**：换一种说法，不增删事实。
  - **问**：缺材料，只能由作者补充；禁止代填。
  - **留**：看起来像套路但实际有功能，保留并在诊断里说明理由。

> E 节规则与附录词表改编自 MIT 许可的开源项目 stop-slop-zh、Humanizer-zh、shuorenhua、humanizer-zh（ai-zixun），致谢见 README。

## A. 句式与修辞：降低重复和表演感（层 1 为主）

| 编号 | 可疑模式 | 处理 | 何时保留 |
|---|---|---|---|
| R01 | 反复"不是 A，而是 B" | 按下方"四分类"判断；虚假对立改成直接说 B 或解释二者关系 | 定义纠错、澄清读者真实误解 |
| R02 | "不仅……更……""既……又……还……"层层加码 | 保留一个主张，明确优先级，删掉没有独立信息的递进 | 需要列明并存条件或权利义务 |
| R03 | 每段都用"三个词、三句话、三点" | 按内容分组，允许一项或四项，不为整齐补出第三项 | 真有三个互不重复的维度 |
| R04 | 连续"真正的 X 是……""本质上……" | 改成有范围的判断，说明"对谁、在什么条件下" | 有论证支撑的概念界定 |
| R05 | "值得注意的是""需要指出的是" | 去掉提示语直接写事实；真有反常结果时说明为什么值得注意 | 重要风险或容易漏读的限制 |
| R06 | "我们不禁思考""这引发一个深刻问题" | 直接提出具体问题，不代替读者表态 | 演讲中有意设置的转场 |
| R07 | 破折号、冒号、括号密集但无功能区别 | 检查句子是否过长；能独立成句就拆开 | 引语、解释、清单及正常停顿 |
| R08 | "归根结底""毋庸置疑""不难发现" | 删除无根据的确定语；补证据或收窄判断 | 命题已证明且读者确需结论 |
| R09 | "赋能、重塑、解锁、闭环、生态"成串 | 写清谁采取什么行动、哪个指标或流程改变 | 专业语境中有明确定义的术语 |
| R10 | 反复"这意味着""换句话说" | 第二句必须带来新推论；否则删除 | 真正降低理解门槛的解释 |

## B. 信息密度：把抽象表扬换成可理解的内容（层 1／层 3）

| 编号 | 可疑模式 | 处理 | 何时保留 |
|---|---|---|---|
| R11 | "高效、精准、便捷、智能、可靠"无依据 | 问具体比较对象、任务、测量方式；没有数据时写功能而非效果 | 已提供可核验的测试结果 |
| R12 | "多维度、全方位、深层次" | 列出实际维度；列不出来就删 | 明确涉及多个独立分析维度 |
| R13 | "显著提升""大幅改善"无数据 | 写实际观察和限制；不得编造百分比 | 有统计检验或可靠比较 |
| R14 | "研究表明、业内普遍认为"无来源 | 标"问"或"待补来源"；或降格为作者判断并说明依据；**不能删掉归属后把论断包装成裸事实** | 有准确引用且未夸大 |
| R15 | 空泛时代开头："在……的今天/浪潮下" | 从任务、冲突、观察或结论切入 | 确实分析时代背景且后文使用 |
| R16 | 同义句反复解释一个主张 | 每段给一句话摘要；同摘要段落优先合并 | 面向初学者的必要复述 |
| R17 | "提供支持、进行优化、实现提升"名词化 | 改成具体动词：改写、核对、删除 | 固定行政或技术表达必须保留 |
| R18 | 人、事、责任被被动句隐去 | 尽可能写明行动主体；未知主体不可猜 | 主体不重要或确实未知 |
| R19 | 用"案例"标签包装泛泛假设 | 区分真实案例、假设例子、示意场景 | 明确标为假设且服务解释 |
| R20 | 细节只是装饰，与结论无关 | 留下能支持判断的细节；没有材料先问 | 文学写作中的氛围和象征 |

## C. 篇章与论证：避免每段同一副模具（层 1／层 3）

| 编号 | 可疑模式 | 处理 | 何时保留 |
|---|---|---|---|
| R21 | 所有段落都是"观点—解释—例子—升华" | 由信息推进决定结构，不强制每段闭环 | 教材或考试确有规定结构 |
| R22 | 标题全是"X：从 A 到 B／赋能新未来" | 换成能区分章节的事实、问题或结论 | 品牌明确要求该修辞 |
| R23 | 什么都列，没有主次 | 问作者最想让读者记住哪件事；删掉不服务目标的分支 | 参考手册确需全面列举 |
| R24 | 好处与坏处永远五五开 | 按证据权重给判断，不制造伪平衡 | 证据确实不足以选边 |
| R25 | 结尾总是"拥抱未来、共同努力" | 以具体行动、已说明的结论或真实未解问题结束 | 演讲或公文明确需要号召 |
| R26 | 每段结尾替读者总结意义 | 删去重复的价值解释，信任读者 | 关键论证节点需要明确推论 |
| R27 | 相关性被写成因果 | 问因果证据；改成"同时出现、可能有关" | 有实验或充分因果识别 |
| R28 | 提建议却没有成本、约束、失败条件 | 补条件或追问；至少说明适用范围 | 简单低风险任务不必展开 |
| R29 | 情节过度单线、反转即和解 | 检查冲突是否被方便地解决，选择是否有代价 | 体裁约定、作者有意选择 |
| R30 | 情绪描写像固定套餐："攥拳、冷汗、胸口一紧" | 避免机械套动作；可直接说感受或用已有独特细节 | 动作确有叙事意义而非装饰 |

## D. 场景与作者：补回不能凭空生成的部分（层 2／层 3）

| 编号 | 可疑模式 | 处理 | 何时保留 |
|---|---|---|---|
| R31 | 写给不同读者却用同一口吻 | 确认受众已知什么、需要决定什么 | 通用说明本面向广泛受众 |
| R32 | 课堂符号、公司模板、术语不一致 | 以用户确认的场景规范为准；冲突请作者选择 | 外部规范优先级已确认 |
| R33 | 叙述突然变成另一种"网红声音" | 用作者样文和明确反馈校准 | 作者主动尝试新风格 |
| R34 | 无材料却写"我曾经、我的客户、实测发现" | 禁止生成；追问真实经历，或改成明示假设 | 作者已提供真实经历 |
| R35 | "我觉得"很多，说不出依据 | 问为什么选这个、放弃哪个、什么会让你改主意 | 私人感受本不需客观证明 |
| R36 | 作者特有词汇被润色掉 | 加作者保留词库；不把方言、节奏一律纠正 | 确实造成歧义或不合场景 |
| R37 | 数字、专名、引用被改写或弱化 | 加事实保护；修改前后核对 | 作者明确纠正原文错误 |
| R38 | 口语化污染专业文体 | 按体裁设置正式程度和术语保护 | 口播稿、随笔允许口语 |
| R39 | 所有不确定性都被清除；同一层不确定性的限定词反复堆叠 | 保留真实条件、未知和争议；压缩重复限定 | 限定承载证据强度、适用范围、法律提示或真实修正 |
| R40 | 为"像人"故意加错字、断逻辑、堆语气词 | 不做；从信息和选择改善自然度 | 引述原文或人物语言，需明确 |

## E. 补充规则（融合自开源项目，层 1／层 2）

| 编号 | 可疑模式 | 处理 | 何时保留 |
|---|---|---|---|
| R41 | 聊天与草稿残留：纯招呼致谢、"以上就是/希望对大家有帮助"、编辑过程叙述（"经过修改后""本稿相比初稿"）、"作为AI我无法……"类免责残留 | 删 | 邮件书信的礼貌用语；真实交付承诺；"截至某日"式时效界定 |
| R42 | 元评论与八股连接词："让我们来探讨""在本文中""首先/其次/综上"整套用满 | 删元评论；连接词按信息结构保留必要者 | 公文、教材、报告的结构要求；确有先后顺序 |
| R43 | 假亲切称呼："朋友们""家人们""宝子们" | 删或改直接称呼 | 口播稿体裁；作者既有风格如此 |
| R44 | 程度副词与虚化量词堆叠："非常/其实/一定程度上"反复出现 | 删后意思不变就删；每处保留真实程度差异 | 强调确有依据、程度本身是信息 |
| R45 | 单句碎片与伪深度格言：戏剧性短句收尾、"这，就是XX的力量""真正的成长是学会与自己和解" | 合并碎片；格言改回具体判断 | 有意强调；被引用的格言；帮助理解的比喻 |
| R46 | 回避"是/有"的虚化动词与拔高尾巴："体现了/彰显了/展现了……的重要性" | 换回直接陈述；删重复赞美的尾巴 | 尾巴带实际信息（原因、结果、目的） |
| R47 | 极端结论与动机脑补："完全取代""彻底结束""只剩一种可能"；无依据推断他人动机或资本阴谋 | 收窄为有证据的判断；先给机制再下判断 | 原文已给出充分论证 |
| R48 | 与假想敌辩论：无内容的"有人可能会说……但是……"自我辩护 | 删 | 澄清读者真实误解；真实反对意见和限制条件 |
| R49 | 排版装饰：粗体滥用、表情符号标题、分隔线堆砌、引号/标点全篇不统一 | 减无效强调；标点按目标格式统一（见附录） | 跳读重点；结构需要；用户声明的样式 |
| R50 | 生造复合词与滥用连接号：自造标签词、多余连字符 | 换成已有定义的说法 | 固定术语；必要英文连字符 |

## 中文特有信号（归入最近规则处理）

- **长定语堆叠**（"一个基于……的面向……的"连环修饰、"的的"连用）→ 按 R07 拆句或 R17 改动词。
- **被字句连用**且隐去行动者 → 按 R18 补主体或改主动；"被认为有关"不等于"导致"。
- **四字词排比**（"提质增效、固本培元、行稳致远"连排）→ 按 R03/R09 处理；公文标题中属惯例的保留。
- **"进行 + 动词"高频** → 按 R17 改直接动词，公文固定搭配除外。

## "不是……而是"四分类（R01 的判断标准）

1. **空洞转折 → 可直接改。** "好的产品不是功能的堆砌，而是价值的重塑。"——A 没被任何人主张，改后也没新增信息。改法：直接说想主张什么。须确认这确实是作者的观点。
2. **虚假二选一 → 重述关系。** "这不是技术问题，而是用户问题。"——只有作者认同该优先级才这样改；若两者都成立，应写"两者都需要核对"。不得擅自替换作者的因果关系。
3. **真实纠错 → 保留。** "匀速运动并不表示没有受力，而是合力为零。"——有明确的纠错对象。注意纠错本身也要学科准确（此处应限定匀速直线运动与惯性系）。
4. **个人风格或演讲节奏 → 保留一次。** 有真实对比信息、全文不反复使用同一转折时，不必处理。

**对每处输出"疑似空转对照"的提示，而不是"检测到禁句"。**

## 附录：候选信号词表（线索，不是黑名单；命中后再做语义判断）

- **程度副词**：非常、十分、极其、相当、特别、格外、尤其、真的、确实、的确、实在（R44）
- **虚化量词/范围**：一种、某种、一定的、相应的、一定程度上、在某种意义上（R44）
- **模糊语气词**：其实、本质上、说白了、客观来讲、坦白说、毋庸置疑（R08/R44）
- **元评论与八股连接**：让我们来探讨、接下来我将、在本文中、下面我们来看、首先、其次、再者、最后、综上所述、总而言之、由此可见（R42）
- **强调虚壳**：值得注意的是、值得一提的是、不得不说、毫无疑问、不容忽视、我们必须认识到（R05）
- **假亲切**：朋友们、家人们、宝子们（R43）
- **金句收尾句式**："这，就是XX的力量""唯有XX，方能XX""在这个XX的时代，我们更需要XX""让我们一起，向着XX前进"（R45/R25）
- **名词化对照**：进行优化→优化；做出选择→选；实现增长→写出具体数字或"涨了"；采取措施→写出具体动作；加以改进→改进；给予支持→支持；提供保障→保障；起到作用→起作用（R17）
- **标点一致性**（R49）：引号全篇统一（"" 或 「」，不混用）；破折号、冒号不密集堆叠；英文多词术语用半角空格（如 `AI Design Agent`），英文术语与中文括号连写不加空格（如 `LLM（大语言模型）`）；品牌名用官方大小写；日期格式统一
